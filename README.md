# 家庭紙卸ホームページ（サンプル）

家庭紙卸の「会社案内＋商品紹介」サイトです。HTML / CSS / JavaScript だけで動くので、ビルドやインストールは要りません。
社名・住所・電話番号・数字はすべて架空です。

## 確認のしかた

`index.html` をダブルクリックすると、ブラウザで表示されます。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | トップページ |
| `products.html` | 取扱商品（カテゴリ切替・検索・詳細表示） |
| `service.html` | サービス・業種別のご提案 |
| `company.html` | 会社概要（ごあいさつ・基本情報・沿革・拠点） |
| `contact.html` | お問い合わせフォーム（入力→確認→完了） |
| `privacy.html` | プライバシーポリシー |
| `js/config.js` | ★会社情報・数字・沿革・お知らせ・フォームの送信先 |
| `js/products-data.js` | ★商品データ |
| `css/style.css` | デザイン（色や文字の大きさは先頭の `:root` で変更できます） |

## 会社情報を差し替える

1. `js/config.js` の社名・住所・電話番号などを書き換えます。全ページに反映されます。
2. 実際の情報にしたら `sampleNotice: true` を `false` にして、上部の「サンプル」の帯を消します。
3. 検索エンジン向けに、各HTMLの `<title>` と `<meta name="description">` の社名も書き換えます。VS Code の「フォルダーを指定して置換」（Ctrl+Shift+H）で「白藍紙業」を一括で置き換えると簡単です。
4. ごあいさつ文・サービス内容・トップページの文章は、各HTMLを直接編集します。

## 商品を追加・変更する

- `js/products-data.js` の `PRODUCTS` に1件ずつ書きます。既存の1件をコピーして書き換えるのが簡単です。
- 写真を使うときは `img/products/` に画像を置き、`image: "img/products/ファイル名.jpg"` と書きます。空のときはイラストが表示されます。
- メーカーの商品名や写真を載せるときは、メーカーの掲載ルールを確認してください。

## お問い合わせフォームの送信先

初期状態はデモ動作で、送信しても内容はどこにも届きません。実際に受け取るには、たとえば Formspree を使います。

1. https://formspree.io でアカウントとフォームを作ります。
2. 表示された URL（例 `https://formspree.io/f/xxxxxxxx`）を `js/config.js` の `form.endpoint` に貼り付けます。
3. 公開したサイトからテスト送信し、メールが届くことを確認します。

## 公開する

フォルダの中身をそのまま、レンタルサーバーや Netlify などの静的ホスティングにアップロードします。
